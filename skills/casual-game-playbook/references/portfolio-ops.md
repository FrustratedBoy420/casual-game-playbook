# Portfolio Operations

## Cadence

| Activity | Target |
|---|---|
| New prototypes | 1–2 per month per small team (20+ over 18 months) |
| Soft launches | Batch 2–3 games in the same week to share UA tests and learnings |
| Live winners | Weekly or bi-weekly updates |
| Portfolio review | Monthly: each title gets KILL / PARK / RESKIN / ITERATE / SCALE |
| Post-mortem | 5 lines for every killed title, kept in a shared log |

## Picking genres

Score each candidate from 1 to 5 and pick the top scores:

| Factor | Question |
|---|---|
| Chart proof | Are 2+ games with this mechanic in the top-200 Puzzle or Casual charts? |
| Audience LTV | Does it appeal to 35+ Tier-1 players? |
| Content cost | Can levels be generated and validated automatically? |
| Ad-ability | Does it look good in a 3-second gameplay clip? |
| Franchise fit | Could it sit under an existing winning brand? |
| Twist clarity | Is the twist (theme, tone, art) clear in one line? |

Proven casual puzzle families: hidden objects, spot the difference, word search, crossword (incl. Scandinavian), math crossword, sudoku variants, sort puzzles (ball, food, colour), jam / escape / unblock, arrow / tap-away, merge, triple match / tile match, colour or sticker by number, jigsaw, solitaire variants.

## Franchise building

1. When a game clears Gate C, name its theme as a brand (e.g. "Calm Grove").
2. The next 1–3 concepts reuse the brand with a new genre: "Calm Grove: Differences", "Calm Grove Crossword".
3. Share art style, icon frame and tone so cross-promo converts well.
4. Turn on cross-promo house ads between siblings.

## Reskin and park

- **Reskin:** for games with good mechanics but weak CPI or weak appeal. Keep the package ID, saves and reviews. Change the art, characters, narrative and title. Release notes: "complete upgrade in art style and narrative". Retest from Gate A.
- **Park:** for games that earn a little organically but don't justify UA. No spend, no updates. Leave them live.
- **Kill:** unlist apps with zero traction to keep the developer page clean. Never delete the code: the mechanics may come back later.

## Team shape (small studio)

| Role | Count |
|---|---|
| Game designer / producer | 1–2 |
| Unity developers | 2–3 (1 owns `_Platform`) |
| Artists (AI-assisted) | 1–2 |
| UA / creative producer | 1 |
| Data / analytics | 1 (part-time at the start) |

## Funding signals

Investors in portfolio studios look for: number of titles with positive unit economics, ROAS curves, payback days, speed (concept to launch), and how repeatable the platform is. Track these from day one.
