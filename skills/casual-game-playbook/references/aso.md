# ASO and Store Listing

## Naming

- **Title pattern:** `Brand: Genre Keyword`, e.g. "Calm Grove: Hidden Objects", "Brainy Grid: Math Crossword". The brand part becomes the franchise umbrella.
- Keep the title under 30 characters (the iOS limit). Put the main search keyword in the title.
- **iOS subtitle (30 characters):** pure keyword plus benefit, e.g. "Relaxing word puzzle game".
- **Android short description (80 characters):** benefit + keyword + "no timers" type promise.

## Package / bundle ID

The Android package name is visible and permanent. Make it descriptive and keyword-rich:

```
com.<studio>.<brand>.<genre>.<keyword1>.<keyword2>
e.g. com.studio.calmgrove.hidden.objects.puzzle
```

Pick it once. It can never change after publishing.

## Description

1. First 3 lines = the hook (shown before "more"): the promise, the feeling, the audience.
2. "HOW TO PLAY" section in 3–5 bullets.
3. "FEATURES" in 5–8 bullets, each starting with a keyword.
4. Repeat 2–3 core keywords naturally. No keyword spam lists (store policy).
5. End with a soft call to action.

Words that match the relaxing positioning: relaxing, cozy, calm, zen, brain training, no timers, no pressure, stress relief, offline, for adults.

## Screenshots and preview video

- First 2 screenshots carry 80% of the conversion. Show the core loop plus one bold benefit headline each.
- Use the same hooks as the winning UA creatives (see `ua-creatives.md`).
- The preview video shows real gameplay in its first 3 seconds.
- A/B test icons and screenshots with Google Play Store Listing Experiments and Apple Product Page Optimization.

## Ratings engine

- Trigger the native review prompt after a positive moment: a level completed after a win streak, or reaching level 10–15.
- Never prompt after a fail, an ad, or in the first session.
- iOS limits the prompt to 3 shows per year, so spend them on high-satisfaction moments.
- Release notes may politely ask happy players for a review. Never offer rewards for reviews.
- Target 4.7★ or higher. Rating is a top driver of store conversion and therefore of CPI.

## Localization

- Launch in English for US / UK / CA / AU.
- Localize the store listing before the game itself. It is cheap and lifts installs in DE / FR / JP / BR.
- Localize the game only for winners with proven ROAS.

## Update cadence

- Winners: weekly or bi-weekly updates (new levels, events, fixes). Freshness helps ranking and retention.
- Parked games: no updates.
